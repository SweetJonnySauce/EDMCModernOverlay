# Superseded Full-Matrix Evidence

This directory preserves the original `fix219_gnome46_pre_migration_v1` oracle and the two valid
long-form captures collected against it. They use 30-second warm-up, 60-second idle CPU,
60-second observation, five configured repetitions, and the original 36-scenario matrix.

The full oracle was superseded before completion because its 180 captures required at least
7.5 hours of fixed manual timing. These captures remain truthful diagnostic evidence but must
not be mixed with, relabeled as, or counted toward the active reduced v2 oracle.
